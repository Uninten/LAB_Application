# 接口与数据字段约定

本文档用于应用端与云平台/嵌入式组员对齐华为云 IoTDA 物模型字段。当前 Web 端采用“前端直连华为云”的课程设计方案。

## 1. 数据来源

Web 页面直接通过 HTTP 请求华为云 IoTDA：

```text
查询实时属性：
GET /v5/iot/{project_id}/devices/{device_id}/shadow

下发控制命令：
POST /v5/iot/{project_id}/devices/{device_id}/commands
```

配置位置：

```text
src/services/config.js
```

配置示例：

```js
DIRECT_HUAWEI: {
  ENABLED: true,
  IOTDA_ENDPOINT: "https://你的-iotda-endpoint",
  PROJECT_ID: "你的-project-id",
  DEVICE_ID: "Lab_Device_01",
  IAM_TOKEN: "临时 IAM Token",
  SERVICE_ID: "LabService",
  INSTANCE_ID: ""
}
```

## 2. 物模型属性字段

| 字段名 | 类型 | 含义 | 示例值 | Web 显示方式 |
|---|---|---|---|---|
| `temperature` | number | 温度 | `26.5` | 温度卡片、温度曲线 |
| `humidity` | number | 湿度 | `58.2` | 湿度卡片、湿度曲线 |
| `smoke` | number | 烟雾浓度 | `320` | 烟雾卡片、烟雾曲线、报警判断 |
| `light` | number | 光照强度 | `680` | 光照卡片、光照曲线 |
| `doorStatus` | number | 门锁状态 | `0`/`1` | 关闭/开启 |
| `fanStatus` | number | 风扇状态 | `0`/`1` | 关闭/开启 |
| `lightStatus` | number | 灯光状态 | `0`/`1` | 关闭/开启 |
| `alarmStatus` | number | 报警状态 | `0`/`1` | 正常/报警中 |
| `RFIDCard` | string | RFID 卡号 | `1DA5D106` | RFID 成员记录 |
| `RFIDStatus` | string | RFID 身份 | `InternalPerson` | RFID 成员记录 |
| `DateTime` | string | RFID 刷卡时间 | `2026-05-28 00:44:42` | 用于判断是否新增一条记录 |

## 3. 状态值约定

| 字段 | 值 | 含义 |
|---|---:|---|
| `doorStatus` | `0` | 门锁关闭 |
| `doorStatus` | `1` | 门锁开启 |
| `fanStatus` | `0` | 风扇关闭 |
| `fanStatus` | `1` | 风扇开启 |
| `lightStatus` | `0` | 灯光关闭 |
| `lightStatus` | `1` | 灯光开启 |
| `alarmStatus` | `0` | 正常 |
| `alarmStatus` | `1` | 报警中 |

## 4. 控制命令约定

Web 按钮会调用华为云命令下发接口，命令名如下：

| Web 操作 | 华为云命令名 | 参数 |
|---|---|---|
| 开门 | `openDoor` | `{ "status": 1 }` |
| 关门 | `closeDoor` | `{ "status": 0 }` |
| 开风扇 | `openFan` | `{ "status": 1 }` |
| 关风扇 | `closeFan` | `{ "status": 0 }` |
| 开灯 | `openLight` | `{ "status": 1 }` |
| 关灯 | `closeLight` | `{ "status": 0 }` |
| 解除报警 | `resetAlarm` | `{ "status": 0 }` |

请求体示例：

```json
{
  "service_id": "LabService",
  "command_name": "openFan",
  "paras": {
    "status": 1
  }
}
```

## 5. 设备影子返回数据说明

Web 会读取设备影子中的 `reported.properties`，例如：

```json
{
  "shadow": [
    {
      "service_id": "LabService",
      "reported": {
        "properties": {
          "temperature": 26.5,
          "humidity": 58.2,
          "smoke": 320,
          "light": 680,
          "doorStatus": 0,
          "fanStatus": 0,
          "lightStatus": 1,
          "alarmStatus": 0,
          "RFIDCard": "1DA5D106",
          "RFIDStatus": "InternalPerson",
          "DateTime": "2026-05-28 00:44:42"
        }
      }
    }
  ]
}
```

## 6. 当前限制

- 设备影子主要用于展示最新状态。
- 历史曲线、门禁记录、报警记录如果不接数据库，前端只能显示空状态或 `?mock=1` 模拟数据。
- 浏览器直连华为云可能遇到 CORS 跨域限制。
