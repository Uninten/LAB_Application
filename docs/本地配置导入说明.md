# 本地配置导入

网页不再从站点加载 `src/services/config.js`。正式访问页面时，用户需要手动选择管理员单独提供的 JSON 配置文件。

## 准备配置

1. 复制仓库根目录的 `config.example.json`。
2. 将副本命名为 `config.local.json`。
3. 填写华为云 IoTDA 参数和凭证。
4. 通过可信渠道把 `config.local.json` 发给目标用户。

`config.local.json` 已被 `.gitignore` 忽略，不要强制提交该文件。

## 使用方法

1. 打开部署后的网页。
2. 点击“选择配置文件”。
3. 选择收到的 `config.local.json`。
4. 校验通过后，页面会自动启动并连接 IoTDA。

配置只保存在当前页面的内存中，不会上传，也不会写入 `localStorage` 或 `sessionStorage`。刷新或关闭页面后需要重新选择。

访问地址添加 `?mock=1` 可以跳过配置导入并使用模拟数据。

## 安全边界

目标用户可以从自己的浏览器内存和开发者工具中获取导入的 AK/SK，因此该方式只适用于可信用户。建议使用权限最小化、可单独吊销的凭证，并定期轮换。浏览器直连 IoTDA 的 CORS 限制仍然存在。
